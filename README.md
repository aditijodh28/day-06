# 🚀 Day 06 — TypeScript + React Employee Management Dashboard

## 📌 Objective

Learn TypeScript and React by building a component-based Employee Management Dashboard.

## 🛠️ Technologies

- TypeScript
- React
- React Hooks
- JSX
- HTML
- CSS
- REST API
- Vite

## ✨ Features

- 📊 Total employee count
- 💰 Average salary
- 🏢 Department statistics
- 🔍 Employee search
- 🏷️ Department filtering
- ↕️ Salary sorting
- 👤 Employee details
- ➕ Add employee
- ✏️ Edit employee
- 🗑️ Delete employee
- ✅ Form validation
- 🌐 API integration
- ⚠️ Error handling
- ⏳ Loading state
- ♻️ Reusable components
- 🎣 Custom React hooks
